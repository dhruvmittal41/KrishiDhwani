# Hardware roles

- ESP32 nodes: actual Wi-Fi-capable board variants to be confirmed.
- I2S MEMS microphones: select by target frequency response and ESP32 compatibility.
- Raspberry Pi: central receiver, supported local Wi-Fi AP and classifier.
- Phone: proposed app on the same local network.

Before wiring, record board versions, microphone voltage, pin mapping, power source and weather protection. No unverified pin assignments, range claims or hardware budget are provided. See the vendor datasheets for the selected components.
