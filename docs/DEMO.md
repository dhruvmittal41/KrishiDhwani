# Demonstration checklist

This is a future integration checklist, not a completed result.

1. Record a short clip using the selected microphone and verify it can be replayed.
2. Display node ID, upload receipt and processing state on the Pi.
3. Classify a supported insect example only after training and evaluation.
4. Show background and uncertain outcomes without forcing a pest label.
5. Display zone, timestamp and model confidence in the app.
6. Record a human inspection decision separately.
7. Disconnect a node and verify stale/offline indicators and recovery.

Label speaker playback as controlled playback. Record microphone, distance, noise and hardware settings for each test. Do not claim field accuracy from a playback demo.
