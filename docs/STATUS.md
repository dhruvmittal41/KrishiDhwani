# Implementation status

Available: project documentation, original animated banner, folder structure, configuration examples, API skeleton and synthetic JSON payload.

Not implemented: ESP32 microphone drivers, wireless upload, persistent intake queue, model training, inference, mobile networking and field validation.

The team reports having demonstration hardware; exact board versions and microphone selection remain to be documented. No model weights, real recordings or experimental results are included.

The API skeleton can start after installing dependencies, but all feature endpoints deliberately return HTTP 501. Flutter is a source placeholder, not a generated runnable application. Firmware is an ESP-IDF skeleton, not a tested board build.
