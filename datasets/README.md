# Insect audio data

No audio is bundled and no download runs automatically.

- Primary: InsectSet459 v1.1 — https://zenodo.org/records/18554693
- Optional annotation research: ECOSoundSet — https://doi.org/10.5281/zenodo.15043892

Use the record's Download controls. Start with the metadata and source README before choosing archives. InsectSet459 covers Orthoptera and Cicadidae; this does not make every label an Indian crop pest. ECOSoundSet is European, so use only relevant overlap or annotation methods.

Retain per-recording creator, licence and attribution. Do not assume one blanket licence covers all recordings. Cross-check shared source recordings if mixing datasets. Preserve the official split as a benchmark and audit leakage before any new split. Crops of a source recording must remain in the same split.

Add local recordings only with independently verified labels. Collect real farm background negatives. Keep private locations and participant details outside public metadata. See metadata.template.csv; store original audio under raw/ and derived clips under processed/ (both ignored).
